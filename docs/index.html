SSH Key Installer

Windows OpenSSH

一条命令，配好 SSH 密钥登录

把当前 Windows 用户的公钥安装到 Linux 或 Windows 服务器。支持跳板机、SSH 配置别名和非标准端口。

PowerShell 5.1+ 交互式
irm https://guajun.github.io/ssh-key-installer/install.ps1 | iex

运行后只需三步

  1. 01输入目标

    例如 root@192.168.1.1 或 SSH Host 别名。

  2. 02选择系统

    Linux 或 Windows；也可以让脚本自动检测。

  3. 03输入密码

    密码由系统 SSH 直接读取，脚本不会接触或保存。

可检查、可验证

私钥始终留在本机

脚本仅向远端发送公钥，保留 SSH 主机指纹检查，并在安装后使用纯密钥模式验证登录。

敏感环境可先下载并检查脚本，再对照 Release 中的 SHA-256。
